# CRM Sales Opportunity Dashboard

#### Summary:  
Interactive spreadsheet dashboard tracking MavenTech's quarterly sales performance.

#### Problem/Objectives:  
New CRM had no external reporting; cleaned data, ran pivot-table EDA, built a dynamic dashboard.

#### Tech Stack:  
Excel, XLOOKUP (joined Manager/Region from sales team table), pivot tables, charts.

#### Data Structure:  
Sales team fields (manager, regional_office) joined to Sales Team table (opportunity_id, sales_agent, product,	account	deal_stage	won_deal	engage_date	close_date	close_value
); 7 products.

#### Insights:  
Q4 had highest win volume, Q1 highest win rate although the data begun from March so it should be considered carefully;  
Q4 2017: 1,196 won (-4.9% QoQ), 60:40 win/loss; top agent Darcel Schlecht.

#### Recommendations:  
Investigate Q4 decline against 2nd and 3rd Quarter.
